# task_02: Циклический сдвиг UTF-8

![task 02](../../badges/tasks/task_02.svg)

`func rotateRunes(s string, shift int) string` циклически сдвигает руны влево на shift позиций. Отрицательный shift означает сдвиг вправо; величина может превышать длину и быть минимальным int. Пустая строка даёт пустую строку. Работаем с кодпоинтами, не графемами. Некорректный UTF-8 преобразуется как `[]rune(s)` (RuneError на каждую ошибку декодирования). Примеры: `rotateRunes("А🙂Б",1)` → `"🙂БА"`; с -1 → `"БА🙂"`; с 3 → исходная строка. O(n) времени и памяти.

Меняйте только solution.go. Используйте stdlib. Проверка: `go test -race -count=4 ./tasks/task_02`.
