# task_02: Циклический сдвиг UTF-8

![task 02](../../badges/tasks/task_02.svg)

```go
func rotateRunes(s string, shift int) string
```

Циклически сдвигает руны строки влево на `shift` позиций.

- Отрицательный `shift` сдвигает вправо.
- `shift` может быть больше длины строки по модулю и может равняться `math.MinInt`.
- Единица сдвига — руна (code point), не графема.
- Некорректный UTF-8 декодируется так же, как `[]rune(s)`: каждая ошибка декодирования даёт `utf8.RuneError`.
- Пустая строка остаётся пустой.
- O(n) по времени и памяти.

```go
rotateRunes("А🙂Б", 1)  == "🙂БА"
rotateRunes("А🙂Б", -1) == "БА🙂"
rotateRunes("А🙂Б", 3)  == "А🙂Б"
```

Проверка: `make task_02`.
