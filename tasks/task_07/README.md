# task_07: Потокобезопасный LRU с теми же правилами

![task 07](../../badges/tasks/task_07.svg)

Тот же LRU-кэш, что в [task_06](../task_06/README.md), — типы, имена и правила без изменений, — но потокобезопасный. В том числе `Set` существующего ключа **не меняет давность**, а успешный `Get` меняет.

- `Get` и `Set` вызываются из нескольких горутин одновременно. Каждая операция атомарна: без гонок, разорванных значений, паник и взаимных блокировок.
- `Get` меняет порядок давности, поэтому ему нужна эксклюзивная блокировка.
- `Get` и `Set` — O(1) в среднем.
- `capacity <= 0` выключает кэш: ничего не сохраняется.

Пакет самостоятельный: перенесите сюда решение task_06 и добавьте синхронизацию.

Проверка: `make task_07`.
