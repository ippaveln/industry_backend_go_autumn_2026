# task_07: Потокобезопасный LRU с теми же правилами

![task 07](../../badges/tasks/task_07.svg)

Контракт, типы и имена из task_06 сохраняются полностью: обновление существующего ключа через Set **не меняет давность**, успешный Get меняет. Реализуйте их в этом самостоятельном пакете и добавьте потокобезопасность. Операции Get/Set должны быть атомарны относительно друг друга, без гонок, разорванных значений, паник и взаимных блокировок. Get изменяет порядок, поэтому требует исключительной блокировки. Средняя сложность O(1). Capacity <= 0 отключает хранение. Можно перенести своё решение task_06 и добавить синхронизацию.

Меняйте только solution.go. Используйте stdlib. Проверка: `go test -race -count=4 ./tasks/task_07`.
