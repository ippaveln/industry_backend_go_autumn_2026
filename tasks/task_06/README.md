# task_06: LRU: чтение обновляет давность

![task 06](../../badges/tasks/task_06.svg)

```go
type LRU[K comparable, V any] interface {
	Get(K) (V, bool)
	Set(K, V)
}

func NewLRUCache[K comparable, V any](capacity int) *LRUCache[K, V]
```

`*LRUCache[K, V]` реализует `LRU[K, V]`: кэш на `capacity` ключей с вытеснением самого давно использованного.

- Успешный `Get` делает ключ самым свежим.
- `Set` нового ключа добавляет его как самый свежий. Если кэш заполнен, перед этим вытесняется самый давний ключ.
- **`Set` существующего ключа меняет только значение, место ключа в порядке давности не меняется.**
- Промах `Get` ничего не меняет и возвращает нулевое значение `V` и `false`.
- Нулевые значения хранятся как обычные.
- `capacity <= 0` выключает кэш: ничего не сохраняется.
- `Get` и `Set` — O(1) в среднем: map и двусвязный список (`container/list`).
- Потокобезопасность не нужна.

```go
c := NewLRUCache[string, int](2)
c.Set("a", 1)
c.Set("b", 2)
c.Set("a", 3) // давность "a" не меняется
c.Set("c", 4) // вытесняется "a"; если перед этим вызвать Get("a"), вытесняется "b"
```

Проверка: `make task_06`.
