# task_06: LRU: чтение обновляет давность

![task 06](../../badges/tasks/task_06.svg)

Реализуйте `LRU[K comparable,V any] interface { Get(K)(V,bool); Set(K,V) }`, `LRUCache[K,V]` и конструктор `NewLRUCache[K,V](capacity int) *LRUCache[K,V]`. Успешный Get делает ключ самым свежим. Новый Set вставляет самый свежий ключ и при заполнении вытесняет самый давний. **Set существующего ключа меняет только значение, сохраняя его место в порядке давности.** Промах ничего не меняет и возвращает zero V,false. Capacity <= 0 отключает хранение. Нулевые значения сохраняются. Get и Set в среднем O(1); используйте map и двусвязный список. Потокобезопасность не требуется. Пример при capacity=2: Set(a,1), Set(b,2), Set(a,3), Set(c,4) вытесняет a; если перед последним Set вызвать Get(a), вытесняется b.

Меняйте только solution.go. Используйте stdlib. Проверка: `go test -race -count=4 ./tasks/task_06`.
