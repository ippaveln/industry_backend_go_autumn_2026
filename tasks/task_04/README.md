# task_04: Агрегация изменений

![task 04](../../badges/tasks/task_04.svg)

`type Stats struct { Count int; Sum, Min, Max int64 }` и `func Calc(nums []int64) Stats`. Посчитайте статистику **разностей соседних значений** `nums[i]-nums[i-1]`, i от 1. При длине меньше двух верните Stats{}. Пример: [10,13,8,8] → Count:3, Sum:-2, Min:-5, Max:3. Вход не изменять. O(n) времени, O(1) дополнительной памяти, без сортировки и промежуточного среза. Входные данные гарантируют, что разности и промежуточные суммы помещаются в int64.

Меняйте только solution.go. Используйте stdlib. Проверка: `go test -race -count=4 ./tasks/task_04`.
